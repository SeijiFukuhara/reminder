# リマインダーアプリ 要件定義書

- 作成者: SeijiFukuhara
- 更新日: 2026-10-05

## 1. 概要

日々のタスクとメモを登録するタスク管理アプリ。
毎日、その日のタスクと今日のメモが表示される。

- 利用者: 自分のみ
- 動作環境: Windows のデスクトップアプリ（Python + tkinter）

## 2. 使い方

今日のタスク一覧とメモが表示されるので、タスクが完了したらチェックボックスにチェックを入れる。
完了したタスクは、完了済みタスクとして別ページで確認できる。

## 3. 機能要件

### 3.1 タスクの登録

タスクを登録するときは、次の項目を選択する。

| 項目 | 内容 |
|------|------|
| 期日の有無 | 期日を設定するかどうか。設定する場合は日付を入力する |
| 完了後も表示し続けるか | 完了しても翌日以降も表示し続ける（毎日のメール確認などのタスク向け）。チェックは日ごとに記録する |
| いつまで表示するか | 「完了するまで（継続タスクはずっと）」「期日まで」「指定した日まで」から選ぶ |
| 表示開始日 | この日からホームに表示する（初期値は今日、またはホームで表示中の日） |

- 各タスクにはメモを別でつけられる。
- リンクを簡単に保存できる（URL入力欄、クリップボードからの追加）。保存したリンクはクリックでブラウザが開く。

### 3.2 今日のメモ

- タスクとは別に、その日のスケジュールをテキストで書いて保存する（例: 何時から何をする）。
- 別の日の「今日のメモ」も記入できる。
- 入力内容は自動で保存する。

## 4. 画面

| 画面 | 内容 |
|------|------|
| ホーム | 指定した日のタスクとメモを表示する。前日・翌日・今日・日付指定で別の日のホーム画面へ移動できる |
| タスク登録 | タスクの登録・編集 |
| 完了済みタスク | 完了済みのタスクを日ごとに表示する。未完了に戻すこともできる |
| 登録済みタスク・メモ | 登録済みのタスクとメモの一覧。編集・削除ができる |

## 5. 制約

- すべてひとつのウインドウで完結させる。別の画面はタブとして表示し、別ウインドウを開く仕様にしない（削除の確認なども画面内で行う）。

## 6. 表示ルールの詳細

- 通常タスク: 表示開始日から表示し、完了した日までは表示する（完了した日は取り消し線つきで表示）。翌日以降は表示しない。
- 継続タスク（完了後も表示し続ける）: 完了しても翌日は未完了の状態で表示する。
- 「期日まで」「指定した日まで」を選んだタスクは、その日を過ぎたら表示しない。
- 期日を過ぎた未完了の通常タスクは「期限切れ」として赤字で表示する。
- 並び順: 未完了 → 完了、その中は期日の近い順。
